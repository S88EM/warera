# ⚔️ WarEra Suite — Home Assistant Add-on & Market Scanner 🤖🏰

Офіційний репозиторій додатка **WarEra Suite** для **[Home Assistant](https://www.home-assistant.io)** та автономного сканера ринку гри **[WarEra](https://warera.io)**.

Репозиторій підтримує автоматичне встановлення та оновлення додатків безпосередньо через **Магазин додатків Home Assistant (Add-on Store)**.

---

## 🚀 Як додати репозиторій та встановити додаток у Home Assistant

### Крок 1. Додавання репозиторію в Home Assistant:
1. У Home Assistant відкрийте: **Налаштування** (Settings) $\rightarrow$ **Додатки** (Add-ons) $\rightarrow$ **Магазин додатків** (Add-on Store).
2. У правому верхньому кутку натисніть меню (три крапки **`⋮`**) $\rightarrow$ **Репозиторії** (Repositories).
3. У полі введення додайте URL цього репозиторію:
   ```text
   https://github.com/S88EM/warera
   ```
4. Натисніть **«Додати»** (Add) та **«Закрити»** (Close).

### Крок 2. Встановлення додатка:
1. Оновіть сторінку або натисніть `⋮` $\rightarrow$ **«Перевірити оновлення»** (Check for updates).
2. У списку репозиторіїв з'явиться категорія **«WarEra Home Assistant Add-ons»**, а в ній — додаток **«WarEra Suite»**.
3. Натисніть на додаток і виберіть **«Встановити»** (Install).

### Крок 3. Налаштування та запуск:
1. Перейдіть на вкладку **«Конфігурація»** (Configuration) додатка.
2. Вкажіть ваші сесійні дані WarEra (Cookie, API Key) та параметри Telegram (якщо потрібні сповіщення).
3. Натисніть **«Зберегти»** (Save).
4. На вкладці **«Інформація»** (Info):
   * Увімкніть **«Запускати під час завантаження системи»** (Start on boot).
   * Увімкніть **«Показувати на бічній панелі»** (Show in sidebar) для доступу через Ingress.
   * Натисніть **«Запустити»** (Start).

## 🌟 Можливості WarEra Suite

### 1. 🌐 Інтерактивний Веб-дашборд (Home Assistant Ingress)
* Сучасний темний веб-інтерфейс, доступний безпосередньо з бічного меню Home Assistant (або за адресою `http://<IP_HA>:8080`).
* **Стрічка вигідних цін (Live Deals):** миттєве виявлення демпінгових лотів з точними статами (`Atk`, `Crit`, `Armor`, `Dodge`, `Prec`, `CritDmg`), якістю ролу статів (0–100%) та позначкою `🌟 ТОП РОЛ`.
* **Пряме посилання на покупку:** кнопка `[ 🛒 Купити на WarEra ↗ ]` перенаправляє на відповідний маркет предмета в 1 клік.
* **Швидкі фільтри:** вибір рідкості (Т1–Т6: від Common до Mythic), типів слотів (зброя, шоломи, броня, штани, чоботи, рукавиці), мінімальної знижки (%) та текстовий пошук.
* **Інспектор ордербуку (Live Order Book):** перегляд відкритих пропозицій по кожному з 36 предметів.
* **Керування сканером з вебу:** кнопки «Пауза / Запуск», моментальний виклик сканування, зміна швидкості (1–10 сек), перемикання методу оцінки (Live / History).

### 2. ⚔️ Інтелектуальний аналізатор спорядження
* **⚡ Live Order Book:** 3-рівнева ієрархія порівняння характеристик (точний збіг статів $\rightarrow$ схожі стати з допуском $\rightarrow$ рол якості).
* **📜 3-денна історія (SQLite DB):** оцінка за медіаною завершених угод з бази на 20 000+ транзакцій.
* **13x прискорення запитів:** HTTP connection pooling перевіряє 24 категорії менш ніж за 0.5 секунди.

### 3. 📱 Telegram-сповіщення та бот-контролер
* Миттєві алерти про знайдені аномалії та демпінг в особисті повідомлення.
* Дистанційне керування через команди: `/mode`, `/clear`, `/interval`, `/quality`, `/roll`, `/status`, `/scan`, `/stats`.

### 4. ⚔️ Purple Sniper (Моніторинг мінімального дамагу для фіолетових речей)
* **Аналіз активних битв у реальному часі:** сканує всі поточні війни та повстання через tRPC API WarEra.
* **🎯 Снайперське вікно (15–20 хв до кінця раунду):** математичний розрахунок часу до завершення раунду (до 300 очок) — видача найточніших даних на стадії, коли пул луту вже стабілізувався і поріг майже зафіксований.
* **Розрахунок порогу входу (Cutoff):** миттєво визначає мінімальну шкоду, яку потрібно нанести в раунді або по всій битві, щоб потрапити в зону розподілу фіолетових речей (Epic T4: снайперки, шоломи, броня, штани, чоботи, рукавиці, а також T5 Лега та T6 Міфік).
* **Індикатор вигідності (🔥 ТОП ЛОТ):** автоматично виділяє битви з наднизьким порогом шкоди (наприклад, менше 100 000 dmg за фіолетову річ).
* **Повний розклад дропу:** перегляд рейтингу учасників битви, закріпленого за ними луту та запасу до "синього" дропу.
* **Telegram-команди `/snipe` та `/battles`:** `/snipe` показує тільки битви на фінішній прямі (15–20 хв), а `/battles` — всі активні точки.
* **👥 Мульти-користувацькі приватні DM (25+ сокланівців без спільних груп):** кожен боєць може написати боту в приватні повідомлення, перевіряти аналітику та увімкнути/вимкнути особисті пуші про фіол (`/sniper_on` / `/sniper_off`).
* **🔒 Повний захист приватності ринку (Privacy Shield):** пошук вигідного спорядження та цін бачить **виключно власник**. Для інших користувачів ринковий функціонал повністю прихований і заблокований.
* **Інтерактивний Веб-дашборд (`/battles` та `http://localhost:8086`):** сучасний темний інтерфейс з фільтрами за часом (Снайперське вікно 15-20 хв / Всі), дамагом, типом битви, пошуком та прямими посиланнями в 1 клік на WarEra. Також інтегровано як публічну кнопку поруч зі Штабом Клану в WarEra Suite.

## 💻 Локальний запуск на ПК або Raspberry Pi (без Home Assistant)

```bash
# 1. Клонувати репозиторій:
git clone https://github.com/S88EM/warera.git
cd warera

# 2. Створити та активувати venv:
python -m venv .venv
source .venv/bin/activate  # Linux / macOS
# або .venv\Scripts\activate на Windows

# 3. Встановити залежності:
pip install -r warera_suite/requirements.txt

# 4. Скопіювати налаштування:
cp .env.example .env
# Заповніть дані у файлі .env

# 5. Запустити повний комплекс (сканер + веб-дашборд + бот):
python run.py

# АБО запустити моніторинг мінімального дамагу для отримання фіолетових речей (Purple Sniper):
python run.py --battles

# АБО вивести ТІЛЬКИ битви у снайперському вікні (15–20 хв до кінця раунду):
python run.py --sniper

# АБО запустити живий термінальний монітор битв (оновлення кожні 15 сек):
python run.py --battles-watch

# АБО запустити інтерактивний веб-дашборд моніторингу фіолетового дропу:
python run.py --battles-web
# (відкрийте http://localhost:8086)

# АБО запустити окремого публічного Sniper Telegram Bot для сокланівців:
python run.py --sniper-bot
```
Відкрийте веб-панель у браузері:
* **Сканер спорядження:** `http://localhost:8080`
* **Purple Sniper (Битви & Фіолетовий дроп):** `http://localhost:8086`

## 📁 Структура репозиторію

* `repository.yaml` — маніфест репозиторію додатків для Home Assistant.
* `warera_suite/` — каталог додатку для Home Assistant OS (`Dockerfile`, `config.yaml`, Ingress Dashboard, Scanners).
* `api/` — єдине джерело істини (SSOT): ядро сканера ринку, бойовий калькулятор та оптимізатор (`combat_calculator.py`, `gear_optimizer.py`, `combat_constants.py`), SQLite-історія (`clan_history_db.py`, `price_history_db.py`), Telegram-боти (`telegram_base.py`, `telegram_bot.py`, `sniper_bot.py`) та модульні веб-шаблони (`templates/*.html`, `templates/*_app.js`).
* `tests/` та `pytest.ini` — модульні тести (`pytest`).
* `sync_suite.py` — синхронізація `api/` у `warera_suite/api/`.
* `run.py` — головний диспетчер локального запуску.
* `install_addon.sh` — скрипт для швидкого встановлення по SSH / Samba.
