# 🚀 Інструкція зі встановлення та запуску WarEra Market Bot

Ця інструкція містить повний покроковий посібник для розгортання, налаштування та запуску бота як на **Raspberry Pi (Home Assistant OS / Alpine Linux / Debian)** для цілодобової роботи 24/7, так і на локальному комп'ютері (Windows).

---

## 🍓 Варіант 1: Встановлення та запуск на Raspberry Pi (24/7 моніторинг)

### Крок 1. Перенесення архіву з комп'ютера на Raspberry Pi
У проекті на ПК вже зібрано архів `warera.tar.gz` з усіма скриптами, бібліотеками, готовими налаштуваннями бота та попередньо завантаженою базою (20 200+ угод).

Відкрийте **PowerShell** на ПК та виконайте:
```powershell
scp -O D:\Vibecoding\warera\warera.tar.gz esm@192.168.2.40:~/
```
*(Введіть пароль користувача `esm`)*

---

### Крок 2. Розпакування на Raspberry Pi
У терміналі Home Assistant / SSH на Raspberry Pi виконайте:
```bash
# Створюємо робочу директорію, якщо ще немає
mkdir -p /home/esm/warera

# Розпаковуємо архів (зверніть увагу на точний шлях до /home/esm/)
tar -xzf /home/esm/warera.tar.gz -C /home/esm/warera

# Переходимо в папку проекту
cd /home/esm/warera

# Надаємо права на запуск скриптів керування
chmod +x *.sh
```

---

### Крок 3. Створення віртуального оточення та встановлення залежностей
*(Виконується лише один раз під час первинного налаштування)*

Якщо віртуальне оточення `.venv` ще не створено:
```bash
# Для Alpine Linux (Home Assistant OS):
apk add python3 py3-pip
python3 -m venv .venv

# Для Debian / Ubuntu / Raspberry Pi OS:
# sudo apt-get update && sudo apt-get install -y python3-venv python3-pip
# python3 -m venv .venv

# Встановлюємо необхідні бібліотеки
.venv/bin/pip install -r requirements.txt
```

---

### Крок 4. Перевірка налаштувань (`.env`)
Файл `.env` вже налаштовано у проекті, але ви можете переглянути або змінити його:
```bash
nano .env
```
Поточні параметри:
```ini
# API ключ гри WarEra
WARERA_API_KEY=YOUR_WARERA_API_KEY

# Токен вашого Telegram бота (@market_warerabot)
TELEGRAM_BOT_TOKEN=YOUR_TELEGRAM_BOT_TOKEN

# Особистий Chat ID
TELEGRAM_CHAT_ID=YOUR_TELEGRAM_CHAT_ID

# Налаштування сканера спорядження
EQUIPMENT_SCAN_INTERVAL=1
EQUIPMENT_MIN_DISCOUNT=5.0
EQUIPMENT_GOD_ROLL_THRESHOLD=80.0
EQUIPMENT_TO_MONITOR=jet,tank,sniper,rifle,helmet6,helmet5,helmet4,chest6,chest5,chest4,boots6,boots5,boots4,pants6,pants5,pants4,gloves6,gloves5,gloves4
```
*(Зберегти: `Ctrl + O`, `Enter`. Вийти: `Ctrl + X`)*

---

### Крок 5. Перевірка зв'язку з Telegram (Діагностика)
Перед запуском сканера перевірте роботу бота:
```bash
cd /home/esm/warera
.venv/bin/python test_telegram.py
```
Скрипт перевірить валідність токена та надішле тестове сповіщення вам в приватні повідомлення.

---

### Крок 6. Робота у фоні 24/7 (Home Assistant OS / Alpine Linux)

Оскільки термінал Home Assistant працює всередині контейнера Alpine Linux без `systemd`, використовуйте готові скрипти з контролем процесів:

1. **Запустити сканер у фоні (працює після закриття термінала):**
   ```bash
   cd /home/esm/warera
   ./start.sh
   ```
2. **Переглянути логи в реальному часі:**
   ```bash
   ./logs.sh
   ```
   *(Для виходу з перегляду логів натисніть `Ctrl + C`, процес сканера продовжить працювати)*
3. **Зупинити фоновий процес:**
   ```bash
   ./stop.sh
   ```

*(Для звичайного Raspberry Pi OS / Debian з systemd можна використовувати `sudo systemctl enable --now warera-scanner` з файлом `warera-scanner.service`).*

## 🤖 Керування ботом прямо з Telegram (Без SSH!)

Після запуску сканера вам **не потрібно щоразу заходити на сервер по SSH**. Весь контроль доступний через інтерфейс Telegram:

### 1. Інтерактивна панель керування:
Викличте панель командою `/start` або `/menu`. Вона містить живий статус та зручні інлайн-кнопки:
* **`[ ⏸ Зупинити сканер ]` / `[ ▶️ Запустити сканер ]`** — моментально ставить перевірку ринку на паузу або відновлює її (пробудження сканера відбувається миттєво без очікування кінця циклу).
* **`[ 💎 Якість предметів ]`** — відкриває меню керування категоріями рідкості (Т1-Т6) та якістю ролу:
  * Перемикання в 1 клік: `🔴 Міфічні (Т6)`, `🟡 Легендарні (Т5)`, `🟣 Елітні (Т4)`, `🔵 Поліпшені (Т3)`, `🟢 Незвичайні (Т2)`, `⚪ Звичайні (Т1)`.
  * Швидкі пресети: `[ 🏆 Топ (Т4-Т6) ]` та `[ ⚡ Всі якості (Т1-Т6) ]`.
  * Меню налаштування порогу топ-ролу характеристик: `[ 🌟 Поріг ролу (80%) ]` (50%, 60%, 70%, 80%, 85%, 90%).
* **`[ ⏱ Змінити інтервал ]`** — відкриває меню вибору швидкості:
  * `[ ⚡ 1 сек ]` `[ ⚡ 2 сек ]`
  * `[ ⏱ 3 сек ]` `[ ⏱ 5 сек ]`
  * `[ ⏱ 10 сек ]` `[ ⏱ 15 сек ]` `[ ⏱ 30 сек ]`
  * Поточний інтервал відмічається галочкою `✓`.
* **`[ 🔍 Сканувати зараз ]`** — примусово запускає позачергове сканування ринку негайно.
* **`[ 🔄 Оновити статус ]`** — оновлює стан панелі, час останнього скану та кількість знайдених пропозицій.
* **`[ 📊 Статистика бази ]`** — виводить звіт про збережені угоди (20 000+ записів, діапазон дат, періодичність оновлення).

### 2. Швидкі текстові команди:
* `/start` або `/menu` — показати панель керування.
* `/quality` або `якість` / `качество` — відкрити меню вибору якості або перемкнути рівень (`/quality t6 on|off`, `/quality all`, `/quality top`).
* `/roll 80` або `рол 80` — встановити мінімальний відсоток характеристик для статусу 🌟 ТОП РОЛ.
* `/stop` або `стоп` — призупинити сканер.
* `/run` або `старт` — запустити / відновити сканування.
* `/interval 1` — встановити точний інтервал у секундах (від 1 до 3600 сек).
* `/status` або `статус` — поточний стан сканера.
* `/scan` або `скан` — провести перевірку ринку прямо зараз.
* `/stats` — статистика бази угод.
* `/version` або `/ver` — показати встановлену версію (<code>b.0001.12</code>) та останні зміни.

## 🎨 Формат сповіщень у Telegram

Сповіщення оптимізовані для швидкого сприйняття без громіздких картинок на весь екран:
* **Колір рідкості біля назви:**
  * 🔴 **Червоний** — Міфічний (`mythic` / VI тир)
  * 🟡 **Золотий** — Легендарний (`legendary` / V тир)
  * 🟣 **Фіолетовий** — Елітний (`epic` / IV тир)
  * 🔵 **Синій** — Поліпшений (`rare` / III тир)
  * 🟢 **Зелений** — Незвичайний (`uncommon` / II тир)
  * ⚪ **Сірий** — Звичайний (`common` / I тир)
* **Іконка предмета:**
  * 🛩 Винищувач, 🛡 Танк, 🎯 Снайперка, 🔫 Гвинтівка/Пістолет
  * 🪖 Шолом, 🦺 Броня, 🧤 Рукавиці, 👖 Штани, 👢 Чоботи, 🗡 Ніж
* **Пряме посилання на ринок:**
  * Клікабельне посилання внизу веде безпосередньо на потрібний предмет: `https://app.warera.io/market/equipments?item={itemCode}`.


   ```bash
   tar -xzf /home/esm/warera.tar.gz -C /home/esm/warera
   cd /home/esm/warera
   ```
