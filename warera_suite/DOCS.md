# WarEra Suite — Документація додатка Home Assistant 🤖🏰

**WarEra Suite** — це інтегрований комплекс для Home Assistant, що містить:
1. **Equipment & Weapon Scanner**: швидкий аналізатор характеристик зброї та броні з виявленням вигідних цін, демпінгу та топ-ролів.
2. **Ingress Web Dashboard**: сучасний інтерактивний веб-віджет у бічній панелі Home Assistant з таблицею аномалій, фільтрами, інспектором стакану та керуванням сканером.
3. **Telegram Bot**: миттєві сповіщення про знайдені аномалії та вигідні лоти з прямими кнопками переходу на ринок.

---

## ⚙️ Налаштування у Home Assistant

Після встановлення додатка відкрийте вкладку **«Конфігурація»** (Configuration) у Home Assistant — усі параметри можна зручно вмикати/вимикати тумблерами прямо з інтерфейсу:

### 1. Перемикачі модулів (Вкл/Викл):
* `enable_telegram_alerts`: надсилати сповіщення в Telegram.
* `enable_equipment_scanner`: увімкнути сканер зброї та броні за статами.
* `enable_web_dashboard`: увімкнути веб-панель в Ingress бічного меню (рекомендовано).

### 2. Моніторинг категорій спорядження (Т1–Т6):
* `monitor_mythic`: міфічні речі Т6 (Jet, Helmet VI...).
* `monitor_legendary`: легендарні речі Т5 (Tank, Helmet V...).
* `monitor_epic`: епічні речі Т4 (Sniper, Helmet IV...).
* `monitor_rare`: рідкісні речі Т3 (Rifle, Helmet III...).
* `monitor_uncommon`: незвичайні речі Т2 (Gun, Helmet II...).
* `monitor_common`: звичайні речі Т1 (Knife, Helmet I...).

### 3. Режими та пороги:
* `pricing_mode`: метод оцінки — `live` (поточні відкриті ордери) або `history` (3-денна історія угод з бази).
* `equipment_scan_interval`: інтервал сканування спорядження в секундах (за замовчуванням `1`).
* `min_discount_pct`: мінімальна знижка на спорядження (%) для алерту (за замовчуванням `5.0`).
* `god_roll_threshold`: поріг якості ролу (%) для позначки ТОП РОЛ (за замовчуванням `80.0`).

### 4. Ключі та авторизація (попередньо заповнені):
* `telegram_bot_token`: токен вашого Telegram-бота (від `@BotFather`).
* `telegram_chat_id`: ваш числовий Telegram Chat ID.
* `warera_api_key`: ключ API гри WarEra (wae_...).
* `warera_cookie`: ваш активний сесійний Cookie гри WarEra.
* `warera_x_vid`: заголовок `x-vid` вашого браузера.
* `warera_x_gr`: заголовок `x-gr` вашого браузера.

## 🖥️ Як відкрити веб-панель (Ingress)

1. Увімкніть перемикач **«Показувати на бічній панелі»** (Show in sidebar) у вікні додатка.
2. У лівому меню Home Assistant з'явиться новий пункт **«WarEra»**.
3. Натисніть на нього — відкриється повний Веб-дашборд з живими котируваннями, таблицею угод, якістю ролів та швидким переходом до покупки!

## 📜 Журнал подій (Logs)

Всі події, виявлені вигідні шмотки та стан роботи відображаються у вкладці **«Журнал»** (Logs) додатка. Вам більше ніколи не потрібно заходити в термінал через SSH!
