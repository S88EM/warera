# WarEra Market Scanner & Smart Arbitrage Bot 🤖📈

Автономний бот-сканер ринку для гри **[WarEra](https://warera.io)**, створений для роботи 24/7 на **Raspberry Pi** (або локально на ПК). 

Бот сфокусований на **зброї та броні** з інтелектуальним аналізом характеристик (статів) безпосередньо по **відкритих ринкових ордерах** у режимі реального часу.

---

## 🌟 Ключові можливості

### 1. ⚔️ Сканер спорядження за статами (`equipment_scanner.py`)
* **Моніторинг категорій:** Зброя та броня за категоріями рідкості (Т1–Т6) з перемиканням у Telegram в 1 клік.
* **Два режими оцінки вартості (перемикання на льоту):**
  * `⚡ Реальний час (Live Order Book)`: порівняння з відкритими ордерами за 3-рівневою ієрархією (точний збіг статів → схожі стати з допуском → подібний рол якості). Миттєво виявляє свіжий демпінг.
  * `📜 3-денна історія (History DB)`: оцінка за медіаною завершених угод з локальної бази SQLite (20 000+ транзакцій).
* **13x прискорення мережевих запитів:**
  * Постійне HTTP-з'єднання (connection pooling) дозволяє перевіряти 24 категорії спорядження менш ніж за 0.5 секунди.
  * Миттєвий запуск без затримок.

### 2. 📊 Аналітика ринку з термінала (`show_stat_prices.py`)
* `python show_stat_prices.py boots4` — таблиця 3-денних медіан та середніх цін по кожному ролу стату.
* `python show_stat_prices.py -c boots4` — сканування активного ринку з моментальним вердиктом: `🔥 ДУЖЕ ДЕШЕВО` (>15% прибутку), `💎 ДЕШЕВО`, `⚖️ НОРМА`, `📈 ДОРОГО`.
* `python show_stat_prices.py -s` — примусова синхронізація останніх угод.

### 3. 🌐 Інтерактивний Веб-дашборд (`equipment_dashboard.py`)
* Сучасний темний інтерфейс (порт `8080`), сумісний з **Home Assistant Ingress** та локальним переглядом у браузері.
* Стрічка вигідних лотів у реальному часі: назва, іконка, характеристики (стати), якість ролу статів, знижка (%) та очікуваний профіт.
* Прямі кнопки для покупки лоту в грі: `[ 🛒 Купити на WarEra ↗ ]`.
* Фільтри за рідкістю (Т1-Т6), слотами (зброя, шоломи, броня, штани, чоботи, рукавиці), мінімальною знижкою та пошуком.
* Інспектор живого стакану ордерів ринку по кожному з 36 предметів.
* Керування сканером з вебу: пауза/запуск, негайний скан, зміна інтервалу (1с, 2с, 3с...), порогів та перемикання Live/History.

### 4. 📱 Сповіщення в Telegram (`notifier.py`)
* Миттєві Telegram-повідомлення з маркерами рідкості (🔴, 🟡, 🟣, 🔵, 🟢, ⚪), іконками предметів, характеристиками, ціною зі знижкою, розрахунком очікуваного профіту, референсною ціною (ринок або історія) та прямим посиланням на ринок гри.

### 5. 🤖 Дистанційне керування через Telegram (`telegram_bot.py`)
* Повний контроль сканера без необхідності заходити на сервер по SSH!
* **Перемикання режиму оцінки:** кнопка `[🔄 Режим: ⚡ Live | 📜 Історія]` та команда `/mode` для миттєвої зміни алгоритму оцінки з автозбереженням у `.env`.
* **Очищення чату:** кнопка `[ 🧹 Очистити чат ]` та команда `/clear` для пакетного видалення до 100 попередніх повідомлень.
* **Керування якістю (рідкістю) предметів:** кнопка `[💎 Якість предметів]` дозволяє вмикати/вимикати будь-яку з 6 категорій спорядження (Т1-Т6) в 1 клік, обирати пресети `Топ (Т4-Т6)` або `Всі (Т1-Т6)`, та налаштовувати поріг якості ролу статів.
* **Турбо-швидкість сканування:** вибір інтервалу `[⏱ Змінити частоту]` від 1 сек (1с, 2с, 3с, 5с) з моментальним пробудженням циклу.
* Інтерактивна панель керування з інлайн-кнопками: `[⏸ Зупинити]`, `[▶️ Запустити]`, `[🔄 Режим]`, `[⏱ Частота]`, `[💎 Якість]`, `[🧹 Очистити]`, `[🔍 Сканувати зараз]`, `[🔄 Оновити статус]`, `[📊 Статистика]`.
* Швидкі команди меню: `/start`, `/mode`, `/clear`, `/quality`, `/roll`, `/interval <сек>`, `/stop`, `/run`, `/status`, `/scan`, `/stats`, `/version`.

## 🚀 Встановлення та швидкий старт

Повна покрокова інструкція знаходиться у файлі **[`INSTALL.md`](file:///d:/Vibecoding/warera/INSTALL.md)**.

### Швидкі команди для Raspberry Pi:
```bash
# 1. Розпакувати на Raspberry Pi:
tar -xzf /home/esm/warera.tar.gz -C /home/esm/warera

# 2. Перейти в папку:
cd /home/esm/warera

# 3. Перевірити ціни за статами:
.venv/bin/python show_stat_prices.py boots4

# 4. Запустити постійний сканер зброї та броні:
.venv/bin/python equipment_scanner.py
```

```ini
EQUIPMENT_GOD_ROLL_THRESHOLD=80.0
```

## 📁 Структура файлів проекту

* `equipment_scanner.py` — головний фоновий сканер зброї та екіпірування з автооновленням бази.
* `equipment_analyzer.py` — логіка оцінки пропозицій за характеристиками проти 3-денної історії.
* `equipment_data.py` — діапазони ролів статів та функція розрахунку % якості ролу.
* `price_history_db.py` — SQLite база `market_history.db` для розрахунку медіан та вердиктів.
* `sync_history.py` — швидка інкрементальна синхронізація завершених угод через tRPC API.
* `show_stat_prices.py` — CLI-утиліта для перегляду статистики цін та перевірки живого ринку.
* `notifier.py` — модуль сповіщень (Console, Telegram).
* `telegram_bot.py` — інтерактивний Telegram-бот для дистанційного керування.
* `config.py` — конфігурація та змінні середовища.
* `INSTALL.md` — детальна інструкція зі встановлення та оновлення на Raspberry Pi та Windows.
